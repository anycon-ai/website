本政策说明 Anycon 公共 hub **hub.anycon.ai**（下称「本服务」）和本网站 **anycon.ai** 处理哪些个人数据、为什么处理、保留多久。

## 我们是谁

本服务由一位位于中华人民共和国的个人开发者运营（下称「我们」），由其对本政策所述的个人数据负责。联系方式：[contact@anycon.ai](mailto:contact@anycon.ai)。安全漏洞请发到 [security@anycon.ai](mailto:security@anycon.ai)。

Anycon 是开源软件。本政策不适用于：

- 别人运营的 hub，包括你自己部署的 hub：由那个 hub 的运营者负责。
- 运行在你自己机器上的 Anycon 软件（daemon、CLI 和 SDK）：它们的数据留在那些机器上，也不向我们发送任何遥测数据。
- 你配合 Anycon 一起使用的其他服务，例如你机器上的 AI agent 及其模型提供方。

## 本服务怎么工作，hub 看得到什么

你机器上的 Anycon daemon 主动向外连接 hub；你的浏览器、终端和脚本作为客户端连接 hub。hub 在你已配对的设备之间转发消息。

会话内容（提示词、agent 的回复、代码、文件和附件）在 daemon 和每个客户端之间用 Noise 协议端到端加密。hub 转发的是密文，看得到的是元数据：哪台设备在和哪台通信、什么时间、多少字节。会话历史存在你的机器上，不在 hub 上。公共 hub 不开启离线队列，所以设备离线时它不替设备暂存消息，无论加密与否。配对码在 daemon 上生成，从不发给 hub。

**Web UI 的代码由 hub 下发。**恶意的或被攻破的 hub 可以下发改过的 JavaScript，读取你浏览器里的密钥和明文。所以在 hub.anycon.ai 上使用 Web UI，意味着信任我们以及传送页面的网络服务商不会下发被改过的代码。dev server 预览的加载代码同理。敏感的工作请自己部署 hub，或者用 CLI / SDK 连接公共 hub：它们的代码由你自己安装，不经 hub 下发。

## hub 存储哪些数据

hub 的数据库里有以下内容：

- **你的账号**：账号 ID、显示名，以及账号有邮箱时的邮箱地址。注册时的显示名取自你的 GitHub 或 Google 资料里的名字，或者你的 GitHub 用户名，或者邮箱地址「@」前面的部分；你可以在「账号设置」里修改。邮箱是你登录时用的或在设置里添加的，或者是 GitHub、Google 声明已验证的邮箱。
- **关联的登录账号**：每个关联的 GitHub 或 Google 账号，记录提供方和它的稳定用户 ID。我们不存这些提供方的用户名、头像或 access token。
- **你的设备**：账号里的每台设备（daemon、浏览器、CLI 或 SDK 客户端）的设备 ID、名称、它自报的平台（操作系统、架构、客户端版本）、浏览器打开 hub 时用的地址、设备访问 token 的哈希，以及创建、最后在线和吊销的时间。浏览器设备的默认名称类似「Chrome · macOS · hub.anycon.ai」。hub 还记录你的哪些设备彼此配对。
- **浏览器登录会话**：会话 token 的哈希、浏览器的 user agent、IP 地址前缀，以及创建、最后使用和过期的时间。IP 前缀是 IPv4 地址的前三段或 IPv6 地址的前 48 位。数据库从不存完整的 IP 地址。
- **安全记录**：成功和失败的登录（方式、IP 前缀、user agent）、账号创建、邮箱和登录方式的变更、设备的配对、接入和吊销、设备 token 轮换（含 IP 前缀），以及管理员变更。
- **推送订阅**：每个开启了推送通知的浏览器，记录它提供的推送服务地址和密钥。
- **通知偏好。**
- **短期记录**：邮箱登录验证码（存哈希，连同邮箱地址，10 分钟有效）、GitHub 和 Google 登录过程中的状态（10 分钟）、dev server 预览令牌（存哈希，24 小时有效），以及绑定到你节点的预览名称。

套餐额度和限速的计数只在内存里。

hub 不存会话内容、项目文件或附件。会话内容到达 hub 时只是密文，配对码则根本不会到达 hub。

## 服务器日志

hub 的日志记录连接和断开（含设备 ID）、请求的路由（不含参数）、状态码和耗时、限速和额度触发，以及每封邮件、每条推送是否送达。邮箱地址在日志里只以简短的哈希出现。日志从不包含消息内容、token 或验证码。hub 前面的代理和网络服务商可能记录完整的 IP 地址、user agent 和请求时间。

## 邮件和推送通知

- 登录邮件里是登录验证码。
- 通知邮件告诉你：你某个节点上的会话在等你审批或出错了、有设备请求接入某个节点，或者发生了影响账号安全的事。它们用固定模板，只有节点名和一个链接，不含任何会话内容。每一类都可以在「账号设置 → 通知」里开关。
- 推送通知为你的浏览器加密，只包含事件类型、节点 ID 和一个随机的会话 ID，由你的浏览器厂商的推送服务（例如 Google、Mozilla、Apple 或 Microsoft）送达。

## Cookie 和浏览器存储

hub.anycon.ai 用一个 cookie 保持你的登录状态，在 GitHub 或 Google 登录过程中另用一个短期 cookie。它不设置任何统计、广告或跟踪类 cookie。

Web UI 把它的密钥和会话缓存存在你设备上的浏览器存储（IndexedDB）里，这些数据不会发给我们。dev server 预览把访问令牌存在预览站点的浏览器存储里，也不设置我们的 cookie。

anycon.ai 是静态网站，不设置 cookie，不使用统计工具。它的托管服务商可能保留常规的访问日志。

## 我们为什么使用你的数据

- **提供本服务**：让你登录、在你的设备之间转发消息、发送你要求的通知、执行套餐额度。
- **保障本服务和你账号的安全**：限速、安全记录、发现并制止滥用。
- **遵守法律。**

我们不出售个人数据，不把它用于广告或用户画像。我们不使用本服务的任何数据训练 AI 模型。

## 还有谁处理你的数据

- **阿里云**：香港的服务器托管，以及我们邮件的投递。
- **Cloudflare**：hub.anycon.ai 和预览域名的网络传送与防护。Cloudflare 终止 TLS，因此看得到请求的元数据和它传送的 Web UI 代码；会话内容仍然端到端加密。
- **GitHub 和 Google**：仅当你用它们登录时。你的登录经过它们，适用它们各自的隐私政策。
- **浏览器推送服务**：仅当你开启推送通知时。

法律要求时我们可能披露数据。我们能披露的只有自己持有的数据，也就是上面所述的账号数据和元数据。

## 数据存放在哪里

本服务的服务器位于香港特别行政区。如果你从其他地方（包括中国内地）使用本服务，你的数据会传输到香港。上面列出的服务商可能在其他国家处理数据。

## 保留多久

- 账号数据、设备、关联账号和通知设置：直到你删除它们或删除账号。
- 浏览器登录会话：直到你退出登录，或最后一次使用后 30 天。
- 安全记录：90 天。
- 验证码、登录状态和预览令牌：过期后删除，有效期从 10 分钟到 24 小时不等。
- 服务器日志：最多 30 天。
- 备份：最多 30 天。

你可以在「账号设置 → 个人资料」里删除账号。hub 会立即断开你的设备，并删除与账号相关的数据，包括设备、配对关系、登录方式、推送订阅和安全记录。它只保留一条「有账号被删除」的记录，不含 IP 地址和 user agent，和其他安全记录一样 90 天后删除。日志和备份里的副本按上面的期限过期。你机器上的会话历史不受影响。

## 你的权利

你可以在「账号设置」里查看和修改显示名、邮箱、登录方式和设备，也可以随时删除账号。根据你所在地的法律（例如欧盟或英国的 GDPR、中国的《个人信息保护法》），你可能还有权获取你的数据副本、要求更正或删除、限制我们的处理，以及反对处理。行使这些权利请发邮件到 [contact@anycon.ai](mailto:contact@anycon.ai)，我们在 30 天内答复。你也可以向当地的数据保护机构投诉。

## 未成年人

本服务不面向 16 岁以下的人，我们不会有意收集他们的数据。如果你认为有 16 岁以下的人注册了账号，请联系我们，我们会删除它。

## 安全

hub 只存设备 token、浏览器登录会话 token 和验证码的哈希。到 hub 的连接使用 TLS，会话内容在你的设备之间端到端加密。威胁模型和已知限制见 [SECURITY.md](https://github.com/anycon-ai/anycon/blob/main/SECURITY.md)。

## 变更

本政策的变更会发布在本页，并更新顶部的日期。重大变更会在生效前至少 30 天通过邮件（如果你的账号有邮箱）或在本网站上通知你。
