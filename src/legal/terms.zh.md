本条款约束你对 Anycon 公共 hub **hub.anycon.ai**（下称「本服务」）的使用。创建账号或使用本服务，即表示你同意本条款和[隐私政策](/zh/privacy)。如果不同意，请不要使用本服务。

## 1. 我们是谁

本服务由一位个人开发者运营（下称「我们」）。联系方式：[contact@anycon.ai](mailto:contact@anycon.ai)。

## 2. 本服务与软件

本服务是一个托管的 Anycon hub：在你账号里的设备之间转发端到端加密的消息，并下发 Web UI。Anycon 软件以 [Apache License 2.0](https://github.com/anycon-ai/anycon/blob/main/LICENSE) 开源。本条款只涉及托管的本服务，不限制你依据该许可证享有的权利，你随时可以改用自己部署的 hub。

## 3. 你的账号

- 你必须年满 16 岁，并且有能力同意本条款。
- 每人一个账号。不要为了绕过套餐额度而注册更多账号。
- 保管好你的登录方式和设备，丢失的设备要吊销。你对自己账号里发生的活动负责。

## 4. 套餐与额度

- 本服务目前免费。免费套餐每个账号包含一个节点（一台运行 Anycon daemon 的机器），以及「账号设置 → 配额」里列出的其他额度。
- 我们以后可能推出付费套餐。付费套餐会有自己的条款，除非你主动订阅，否则不会向你收费。
- 我们可能调整免费套餐的额度。如果调整会让你现有的用法受限，我们会提前至少 30 天通知。

## 5. 你的机器和你的 agent

Anycon 不是沙箱。你通过 Anycon 使用的 agent 运行在你的机器上，以你的用户身份、带着你的权限运行。由你决定它们可以做什么，包括批准哪些权限请求。你对它们的行为负责，也要遵守你所用的 AI agent 和模型提供方的条款。请备份你的机器：会话历史存在那里，不在本服务上。

不要利用本服务：

- 违反法律或侵犯他人的权利；
- 传播恶意软件，或托管钓鱼、诈骗等欺骗性内容，包括通过 dev server 预览；
- 通过 dev server 预览运营公开的网站或服务（预览用来查看你自己正在开发的东西）；
- 攻击、探测本服务或其他用户，让它们过载，或者绕过限速、套餐额度或安全措施；
- 把本服务当作通用代理、VPN 或文件传输服务使用，或者转售对本服务的访问；
- 为不属于你的邮箱地址请求登录验证码，或以其他方式经由本服务发送不请自来的邮件。

举报滥用请发邮件到 [contact@anycon.ai](mailto:contact@anycon.ai)。
